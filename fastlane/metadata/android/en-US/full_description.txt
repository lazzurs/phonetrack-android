Logging app to Nextcloud PhoneTrack.

Features

    List, create, edit, share, search and delete log jobs
    Start on system boot
    Store positions when network is not available
    Multi-Lingual User-Interface

Requirements

    Nextcloud instance running
    Nextcloud PhoneTrack app enabled

Alternatives

If you dislike this app and you are looking for alternatives: Have a look at other loggin methods/apps
in PhoneTrack wiki.

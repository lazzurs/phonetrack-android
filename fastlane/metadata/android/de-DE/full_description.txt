PhoneTrack ist eine Anwendung zur kontinuierlichen Protokollierung von Standortkoordinaten.
Anwendung funktioniert im Hintergrund. Punkte werden in der gewählten Frequenz gespeichert und in Echtzeit auf einen Server hochgeladen. Dieser Logger funktioniert mit der [https://gitlab.com/eneiluj/phonetrack-oc PhoneTrack Nextcloud App] oder einen beliebigen benutzerdefinierten Server (GET oder POST HTTP-Anfragen).

# Funktionen

- Protokollierung an mehreren Zielen mit mehreren Einstellungen (Frequenz, min. Abstand, min. Genauigkeit)
- Bei PhoneTrack Nextcloud App anmelden (PhoneTrack Log Job)
- Loggen Sie sich auf jedem Server ein, der HTTP GET oder POST-Anfragen empfangen kann (benutzerdefinierter Log-Job)
- Positionen speichern, wenn Netzwerk nicht verfügbar ist
- Beim Systemstart starten
- Geräte einer Nextcloud PhoneTrack-Sitzung auf einer Karte anzeigen
- Dunkles Design
- Mehrsprachiges User-Interface (übersetzt auf https://crowdin.com/project/phonetrack)

# Voraussetzungen

Wenn Sie sich bei Nextcloud PhoneTrack-App anmelden möchten:

- Nextcloud-Instanz läuft
- Nextcloud PhoneTrack App aktiviert

Andernfalls, keine Voraussetzungen! (Außer Android>=4.1)

# Alternativen

Wenn Sie diese App nicht haben und Sie nach Alternativen suchen:
Werfen Sie einen Blick auf die Protokollierungsmethoden/Anwendungen im PhoneTrack Wiki: https://gitlab.com/eneiluj/phonetrack-oc/wikis/userdoc#logging-methods.
